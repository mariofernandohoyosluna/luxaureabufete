# Copia local de referencia — Lux Aurea Bufete Legal

Origen: https://luxbufete-aap35rwy.manus.space/

Esta carpeta contiene una copia local del build público entregado por el sitio del cliente para estudiar su diseño y preparar un update.

## Contenido

- `index.html`: documento publicado y metadatos.
- `assets/index-CUJ0HY3t.js`: bundle JavaScript compilado.
- `assets/index-BrhzjTaH.css`: estilos compilados.
- `manus-storage/`: imágenes públicas utilizadas por el hero, el método y la sección de protección.
- `reference/manifest.webmanifest`: manifiesto PWA publicado.

## Observaciones

- La publicación original es un bundle minificado/compilado; no incluye los componentes React, archivos de diseño ni el repositorio fuente.
- Las rutas de imágenes y assets fueron ajustadas para que la referencia pueda abrirse desde esta carpeta.
- La tipografía se importa desde Google Fonts en el CSS; si se necesita una copia totalmente offline, habrá que descargar y declarar localmente Cormorant Garamond y Manrope.
- Los enlaces de contacto publicados apuntan a WhatsApp y al correo del bufete; no se modificaron.
